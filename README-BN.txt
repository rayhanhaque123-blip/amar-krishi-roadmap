আমার কৃষি রোডম্যাপ — PWA ইনস্টল ও অফলাইন প্যাকেজ

এই ZIP-এ index.html, manifest.webmanifest, sw.js, icon.svg এবং 192/512 পিক্সেলের PNG আইকন আছে।

GitHub Pages-এ বসানোর নিয়ম:
১) ZIP ডাউনলোড করে Extract করুন।
২) GitHub repository rayhanhaque123-blip/amar-krishi-roadmap খুলুন।
৩) সব ফাইল repository-র মূল (root) ফোল্ডারে আপলোড করুন; index.html-কে নতুন index.html দিয়ে Replace করুন।
৪) Commit changes দিন এবং GitHub Pages আপডেট হওয়া পর্যন্ত অপেক্ষা করুন।
৫) Android Chrome-এ https://rayhanhaque123-blip.github.io/amar-krishi-roadmap/ খুলুন।
৬) Chrome-এর ⋮ মেনু থেকে “Install app” বা “Add to Home screen” বেছে নিন।

প্রথমবার সাইট অনলাইনে খুলে লোড হতে দিন। তারপর ইনস্টল করা অ্যাপটি অফলাইনে খোলার পরীক্ষা করতে পারেন। অ্যাপের HTML/ফাইল ক্যাশ থাকলে ইন্টারনেট ছাড়াও খোলা সম্ভব; Google Drive সিঙ্কের জন্য ইন্টারনেট লাগবে।

সতর্কতা: index.html বদলানোর আগে বর্তমান ফাইলের কপি রেখে দিন। একই সাইট/ব্রাউজারের localStorage ও IndexedDB-র হিসাব সাধারণত থাকবে, তবে যেকোনো বড় আপডেটের আগে JSON Export বা Drive backup যাচাই করুন। Client Secret HTML/JavaScript-এ দেবেন না।

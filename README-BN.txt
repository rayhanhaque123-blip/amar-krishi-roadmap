আমার কৃষি রোডম্যাপ — Chrome ইনস্টল ও অফলাইন ব্যবহারের সংশোধিত প্যাকেজ

এই প্যাকেজে index.html, manifest.webmanifest, sw.js এবং আইকন ফাইল আছে।

GitHub Pages-এ আপডেট:
১) ZIP Extract করুন।
২) GitHub repository-র amar-krishi-roadmap ফোল্ডারের root-এ সব ফাইল আপলোড/Replace করুন।
৩) Commit changes দিন।
৪) ২–৫ মিনিট অপেক্ষা করে Chrome-এ এই ঠিকানাটি খুলুন:
   https://rayhanhaque123-blip.github.io/amar-krishi-roadmap/
৫) পেজটি অনলাইনে সম্পূর্ণ লোড হতে দিন। Chrome-এর ⋮ মেনু থেকে “Install app” অথবা “Add to Home screen” নির্বাচন করুন।
৬) ইনস্টল করা অ্যাপটি একবার অনলাইনে খুলে নিন। তারপর Airplane mode চালু করে অফলাইন পরীক্ষা করুন।

খুব গুরুত্বপূর্ণ:
- ZIP ফাইল সরাসরি Chrome-এ খুললে PWA ইনস্টল হবে না; GitHub Pages-এর HTTPS ওয়েব ঠিকানায় প্রকাশ করতে হবে।
- index.html, manifest.webmanifest, sw.js এবং icon-192.png/icon-512.png একই repository root-এ রাখুন।
- আগের অ্যাপ ইনস্টল করা থাকলে আগে ইন্টারনেট চালু রেখে অ্যাপটি খুলুন, তারপর Chrome-এ পেজ refresh করুন। পুরোনো অফলাইন ক্যাশ বদলাতে কিছু সময় লাগতে পারে।
- যদি এখনও ইনস্টল না আসে: Chrome-এ সাইট খুলে ⋮ মেনু দেখুন; “Install app” না থাকলে “Add to Home screen” চেষ্টা করুন।
- অফলাইন ব্যবহারের জন্য প্রথমবার অনলাইনে সাইটটি খুলে সম্পূর্ণ লোড হতে হবে।
- বড় আপডেটের আগে অ্যাপের JSON Export/Google Drive backup যাচাই করুন। এই ফাইল বদলালে স্থানীয় ডেটা সাধারণত মুছে যায় না, তবে ব্যাকআপ রাখা জরুরি।
